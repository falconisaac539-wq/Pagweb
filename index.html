Variables globales

Se definen fuera de cualquier función y se pueden usar desde cualquier parte del código, incluso dentro de funciones.

var nombreGlobal = "Ana";
var contador = 0;

function saludar() {
  return "Hola, " + nombreGlobal;
}
function sumar() {
  contador = contador + 1;   // modifica la global
}
Ejercicio 1. Escribe un nombre para guardarlo en la variable global y llama a la función.

Ahora la función sumar() cambia la global contador cada vez que la llamas:

contador = 0

Conclusión: la variable global conserva su valor entre llamadas porque no vive dentro de la función.

Variables locales

Se definen dentro de una función y solo existen ahí. Fuera de la función no están definidas.

function calcular(n) {
  var resultadoLocal = n * 2;
  return resultadoLocal;
}
calcular(5);          // 10
resultadoLocal;       // Error: no está definida
Ejercicio 2. Escribe un número, la función lo duplica con una variable local y después intentamos leerla desde fuera.
Variable local con el mismo nombre que una global. La local tiene prioridad dentro de la función. 
var color = "azul";           // global
function mostrar() {
  var color = "rojo";         // local
  return color;
}
